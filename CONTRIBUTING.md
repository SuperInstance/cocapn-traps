# Contributing to cocapn-traps

## Getting Started

```bash
git clone https://github.com/SuperInstance/cocapn-traps.git
cd cocapn-traps
pip install -e ".[dev]"
```

## Workflow

1. Fork or branch from `main`
2. Make changes
3. `make lint && make test`
4. Open PR

## Release

Tag `v*` triggers automated PyPI publish.
